# Music Playlist App

## Project Description

I made this application as part of Assignment 3 in my Full-Stack Development course.

The application allows users to search for songs and create their own playlist.

## Features

- Search for songs and artists
- Filter songs by genre
- Sort songs by title, artist or duration
- Add and remove songs
- Calculate the total playlist duration
- Save the playlist using localStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- Git

## Responsive Design

The application is designed to work on both desktop and mobile devices.

## What I Learned

During this assignment, I learned how to work with arrays, objects and DOM manipulation in JavaScript.

I also learned how to use localStorage to save information and how to use Git through the terminal.
